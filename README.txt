Como publicar no Netlify (grátis, sem cadastro):
1. Acesse https://app.netlify.com/drop
2. Arraste ESTA PASTA inteira (não só o arquivo) para a página
3. Você receberá uma URL pública tipo https://random-name.netlify.app/
4. Compartilhe a URL com a diretoria/conselho

- Faça suas mudanças no projeto2

- Rode novamente: python scripts/12_preparar_deploy.py
- Arraste a pasta deploy/ atualizada no Netlify
